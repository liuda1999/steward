## 许可证：MIT → Apache-2.0

唯一的实质差别是**专利授权**。

这个项目要对接各类模型服务和推理框架，使用者很可能身处有专利组合的公司。MIT 对专利是沉默的：没给授权，也没拒绝。沉默不等于安全，等于让每个使用者的法务自己去猜。Apache-2.0 把这件事写清楚：

- 贡献者授予你使用其必要专利的许可；
- 你若就本项目发起专利诉讼，这份许可自动终止。

对使用者的实际影响：

| | |
|---|---|
| 商用 / 修改 / 闭源分发 / 私有部署 | 都可以，不变 |
| 需要遵守 | 保留 `LICENSE` 与 `NOTICE`；改过的文件说明「已修改」；不得用项目名为衍生品背书 |

源码文件首行统一加了 `SPDX-License-Identifier: Apache-2.0`（39 个 `.py`），工具链可直接识别。

> v1.0.0 的 tag 里仍是 MIT。tag 不改写，历史留着。
